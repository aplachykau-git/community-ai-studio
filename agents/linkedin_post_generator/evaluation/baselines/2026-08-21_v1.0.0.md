## Baseline Policy

Future agent, prompt, rubric, fixture, model, temperature, or threshold changes
must be evaluated against this baseline. Create a new baseline only after the
new behavior is intentionally approved. Do not move held-out judge examples into
the few-shot set without replacing them with new human-labeled held-out examples.
